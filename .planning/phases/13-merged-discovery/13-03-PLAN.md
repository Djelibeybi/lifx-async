## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| mDNS advertisement to device candidate | A validated advertisement is still untrusted liveness evidence and must not be yielded directly by default discovery. |
| mDNS transport exception to merged diagnostic | Exception objects and live endpoint text stop at the sweep catch; only bounded stage/reason/class fields may cross into the merger. |
| Direct LIFX response to typed device state | Packet identity, correlation, response type, and Echo payload cross into device construction/state only after validation. |
