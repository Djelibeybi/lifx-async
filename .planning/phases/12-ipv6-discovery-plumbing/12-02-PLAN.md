## Trust Boundaries

| Boundary | Description |
|---|---|
| Untrusted caller text -> address validation | Empty, malformed, and ambiguous link-local input must not acquire a socket |
| Validated literal -> discovery destination | Accepted text selects family/bind and is sent to the requested target without hidden route assumptions |
| IPv6 response sockaddr -> targeted Device construction | The OS may separate link-local host and scope ID; the validated caller target must retain its zone |
