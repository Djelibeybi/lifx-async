# Phase 09 Plan 01: Theme Data Contract & Catalogue Resync

> **Reconstructed record.** This plan was written on 2026-08-27, after the work
> shipped. The work was executed directly on the `split/library-changes` branch
> and landed as a single commit, `291e7e6` (2026-08-19), outside the GSD
> plan → execute → verify loop. The plan is reconstructed from that commit so
> Phase 9 has an auditable record; it did **not** precede execution and must not
> be read as though it did. Its `must_haves` are derived from the phase's
> ROADMAP success criteria and the commit's own stated intent, and every one is
> checked against the shipped tree in `09-VERIFICATION.md`.

## Objective

Make the generated catalogue the product of a validated, importable data
contract rather than a private arrangement inside the generator, and resync the
catalogue from a source that is not bounded by what a device can report back.

## Context

The generator owned the theme record contract privately, so nothing outside
`scripts/generate_theme_data.py` — which is not in the wheel — could validate a
record. The palettes it emitted were a replication of the LIFX app's own uint16
rounding applied to values that had already been truncated by a device readback,
so 25 themes silently lost every colour past the sixteenth.

## Tasks

### Task 1: Extract the record contract into `lifx.theme.schema`

Move `canonical_palette`, `load_theme_records`, `validate_key` and
`validate_records` out of the generator into an importable library module that
ships in the wheel but stays out of `lifx.theme.__all__` and the published API
docs, matching the existing `Canvas` precedent. Point the generator at it.

### Task 2: Store colours as floats and stop truncating at 16

Store colours as user-facing HSBK floats (hue 0–360, saturation and brightness
0–1, kelvin), converted to wire values at runtime by the existing
`HSBK.to_protocol()`. Accept palettes longer than the 16 slots a MORPH wire
packet carries. Resync the catalogue from the LIFX Cloud API rather than a
device readback.

### Task 3: Move slug derivation to one leaf module

Move slug derivation into `lifx.theme.slug`, a leaf module whose only import is
`re`, shared by `ThemeLibrary` and the generator. Apostrophes are dropped rather
than collapsed to an underscore, `&` expands to `and`, and every other run of
non-slug characters becomes a single `_`.

## Verification

- The full suite passes with `data.py` regenerating byte-identically.
- `lifx.theme.schema` imports without reaching into `scripts/`.
- Every pre-6.3.0 key and every rename alias still resolves.
