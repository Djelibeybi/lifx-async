# Phase 09 Plan 02: Built-in Theme Catalogue Documentation

> **Reconstructed record.** This plan was written on 2026-08-27 alongside the
> work it describes, rather than before it. The work landed as `874f073` on
> `chore/v1.2-closeout-v1.3-setup`. It is reconstructed here so Phase 9 has an
> auditable record; every `must_have` is checked against the shipped tree in
> `09-VERIFICATION.md`.

## Objective

Give the shipped theme library a documentation page that lists its themes and
categories and records that the redefined pre-6.4.0 palettes were not carried
forward — the phase's one remaining success criterion.

## Context

The page that satisfied this criterion was written on the unmerged
`codex/api-theme-generation` branch and never reached `main`. The theme-resync
split landed that branch's library-facing work (the `lifx.theme.schema`
extraction, plan 09-01) and moved the tooling to the private `lifx-theme-resync`
repository, but the catalogue page — which the split design listed as staying
here — was not carried across.

Two things about the source page had gone stale in the meantime. Its fidelity
section described the Phase 8 device-readback boundary as the live constraint,
which plan 09-01's API resync superseded. And it claimed a documentation
contract test compared its table against the live library; that test belonged to
the tooling and went with it, so the claim was true of no test in this
repository.

## Tasks

### Task 1: Land the catalogue page

Port `docs/getting-started/built-in-themes.md` with its category/count table,
three executable enumeration examples, and the compatibility statement. Add nav
entries to both the site nav and the llmstxt section list. Drop the link to the
runbook, which now lives in another repository.

### Task 2: Correct the fidelity section for what shipped

Replace the device-readback boundary with the post-resync reality: palettes are
not truncated to the 16 slots a firmware effect packet carries, 25 themes exceed
16 colours, and that length is available to `apply_theme()` but not to
`MatrixEffect`, which still rejects a palette above `MAX_PALETTE_COLORS`.

### Task 3: Make the claimed contract test real, and de-duplicate

Add `tests/test_theme/test_docs_catalogue.py`, deriving every documented total
from the records rather than restating it. Point `docs/api/themes.md` and
`docs/getting-started/themes.md` at the catalogue instead of carrying their own
copies, and correct the resolvable-key count from 168 to 169.

## Verification

- The contract test fails on a perturbed count, not merely passes as authored.
- `zensical build` is clean.
- No `theme-resync`, `theme_resync` or `theme-capture` reference survives in
  `docs/`, `src/` or `mkdocs.yml`.
